VITALSTAR VE PRO
================

A browser-based video editing prototype for RexWeb Nexora.

FILES
-----
index.html - Editor layout and controls.
style.css  - Responsive dark interface.
app.js     - Video editor interactions.

HOW TO OPEN
-----------
Open index.html through the RexWeb Nexora website after committing the files to GitHub.

FEATURES
--------
- Import videos, images, and audio files.
- Preview videos and photos.
- Add media to a visual timeline.
- Add text overlays.
- Split and delete timeline clips.
- Basic preview effects and adjustments.
- Change preview aspect ratios.
- Undo and redo timeline changes.
- Save project drafts in the current browser.

LIMITATIONS
-----------
This is an early prototype. MP4 export is not yet implemented.
It does not yet combine all tracks into a finished video.
Saved drafts are stored in the current browser.
Imported media may need to be selected again in a new session.

IMPORTANT
---------
Keep all four files inside the video-editor folder.
Test the editor before connecting it to the main website.
